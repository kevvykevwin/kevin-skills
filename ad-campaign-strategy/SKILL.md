# Ad Campaign Strategy

Framework for planning and executing paid media campaigns across platforms and managed service partners.

## Decision Tree: Platform vs Direct Buy

### When to Use Platform/Self-Service
- Budget < $50k/month per channel
- Need rapid iteration and testing
- Direct response objectives
- Full control over targeting and creative
- In-house media buying capability

**Platforms:** Meta, Google, TikTok, LinkedIn, Pinterest, Twitter/X, Snapchat

### When to Use Direct Buy/Managed Service
- Budget > $25k/month for premium inventory
- Brand awareness objectives
- Need specific placements or sponsorships
- Seeking premium/non-skippable inventory
- Want white-glove service and insights

**Partners:** Spotify, Hulu/Disney+, Vox Podcast Network, NBC/Universal, HBO, programmatic DSPs

## Platform Campaign Workflow

### Step 1: Campaign Structure Decision

**Campaign Organization:**
- **Initiative-Based (Preferred for ABO):**
  - Always On campaigns
  - Specific lead gen campaigns
  - Seasonal/promotional campaigns
  - Each initiative = separate campaign

- **CBO vs ABO:**
  - No general preference - depends on setup
  - ABO (Ad Set Budget Optimization) = Better for initiative-based structure
  - CBO (Campaign Budget Optimization) = Better for unified objectives

### Step 2: Campaign Setup

**Core Settings:**
1. **Objective** - Align to business goal (awareness, consideration, conversion)
2. **Flighting** - Start/end dates, always-on vs pulsing
3. **Budget** - Daily vs lifetime, refer to fractional-cmo-frameworks for allocation
4. **Geo Targeting** - See platform-specific nuances in references/platform-setup-guides.md

**Critical for Success:**
- Naming conventions for tracking
- Conversion tracking setup
- Attribution windows
- Budget pacing rules

### Step 3: Targeting Strategy (MOST CRITICAL)

**Platform-Specific Hierarchy:**

**Search (Google, Bing):**
- PRIMARY: Contextual (keywords, search intent)
- SECONDARY: Audience (remarketing, customer match)
- Use references/targeting-strategy.md for keyword frameworks

**Social (Meta, TikTok, LinkedIn):**
- PRIMARY: Audience (cohorts, lookalikes, customer lists)
- SECONDARY: Interests/Behavioral
- TERTIARY: Contextual (placement, topic)
- Audience graph is the strength of these platforms

**Display/Programmatic:**
- BALANCED: Contextual + Audience
- Use both for best performance

### Step 4: Targeting Execution

Break targeting into three categories:

**1. Audience (Cohorts)**
- Custom audiences (email lists, website visitors, app users)
- Lookalike/similar audiences
- CRM-based segments
- Customer lifetime value cohorts

**2. Contextual**
- Keywords (search)
- Topics/categories
- Placements
- Content alignment

**3. Interests/Behavioral**
- Platform-defined interest categories
- Purchase behaviors
- Engagement behaviors
- Life events

See references/targeting-strategy.md for detailed frameworks.

### Step 5: Platform Execution

Each platform has unique best practices. See references/platform-setup-guides.md for:
- Meta/Facebook (ABO for initiatives, creative best practices)
- Google Search (Hagakure structure, geo nuances, search-only campaigns)
- TikTok (creative-first approach, sound-on optimization)
- LinkedIn (B2B targeting, professional attributes)
- Pinterest (visual search, shopping behavior)

## Direct Buy Workflow

### Step 1: Vendor Selection

**Questions to Answer:**
- Which tech vendor fits our needs?
- What about their tech is applicable to this client?
- What targeting capabilities do they offer?
- What's their minimum spend?
- What's their attribution/reporting capability?

**Vendor Categories:**

**Programmatic DSPs:** Broad reach, algorithmic optimization
- The Trade Desk, StackAdapt, Adroll, etc.
- See references/vendor-directory.md for full list of 15-20 partners

**Premium/Direct Partners:** High-quality, brand-safe inventory
- Spotify, Hulu/Disney+, Paramount+
- Vox Podcast Networks, NBC/Universal, HBO
- See references/vendor-directory.md for capabilities

**Niche Partners:** Specific placements or formats
- GumGum (contextual), limited for small business focus
- See references/vendor-directory.md for selective list

### Step 2: Vendor Outreach

**Contact Discovery:**
1. Do we have account manager emails?
   - YES → Use existing relationship
   - NO → Find contacts via:
     - LinkedIn Sales Navigator
     - Company website contact forms
     - Industry connections
     - RFP submission portals

2. Prioritize:
   - Existing account managers (faster)
   - Sales team (may require vetting process)
   - Partnership teams (for strategic deals)

### Step 3: RFP Process

Use templated RFPs to scale outreach efficiently.

**RFP Must Include:**
- Client business blurb
- Campaign budget
- Flight dates
- Audience target description
- Timing/deadlines
- Reporting requirements

See references/rfp-templates.md for:
- Standard RFP template
- Channel-specific variations
- Follow-up email templates

**Templatization Approach:**
Create master template with [BRACKETS] for easy find-replace:
- [CLIENT_NAME]
- [BUSINESS_DESCRIPTION]
- [BUDGET]
- [FLIGHT_DATES]
- [AUDIENCE_TARGET]

### Step 4: Vendor Evaluation

**Evaluate Responses On:**
- CPM/pricing competitiveness
- Targeting capabilities match
- Reporting/attribution clarity
- Minimum spend requirements
- Creative requirements
- Campaign management support

**Maintain Performance Database:**
Track vendor performance over time to refine directory (see references/vendor-directory.md for review process).

## Best Practices

**Campaign Structure:**
- Keep initiatives separate for clear measurement
- Use consistent naming conventions
- Build in testing budget (10-20% of total)
- Plan for learning phase (7-14 days)

**Targeting:**
- Start narrow, expand based on performance
- Layer targeting thoughtfully (don't over-restrict)
- Always have remarketing running
- Test new audiences in separate ad sets

**Budget Management:**
- Refer to fractional-cmo-frameworks for allocation
- Set appropriate daily minimums for learning
- Monitor pacing daily for first week
- Build in buffer for platform delivery fluctuations

**Optimization:**
- Wait for statistical significance before changes
- Make one change at a time
- Document all changes for learning
- Review performance weekly minimum
