# Google Ads Launch Checklist

Pre-launch verification steps before activating campaigns.

## Account Setup

- [ ] Conversion tracking configured and firing correctly
- [ ] Google Analytics linked (if applicable)
- [ ] Billing information verified
- [ ] Account-level goals set

## Campaign Settings

For each campaign, verify:

- [ ] Search Partners: OFF
- [ ] Display Partners: OFF
- [ ] Start date: Today (or scheduled date)
- [ ] End date: None (unless time-bound promotion)
- [ ] Location: Correct geography selected
- [ ] Location targeting: "People in or regularly in your targeted locations"
- [ ] Budget: Daily budget set correctly
- [ ] Bidding: Maximize Conversions (initial) or appropriate strategy

## Ad Groups

- [ ] Naming follows convention: `campaign_ad.group_match.type`
- [ ] Keywords properly match-typed (Exact/Phrase)
- [ ] Negative keywords applied at campaign/ad group level
- [ ] Ad rotation set appropriately

## Ads

- [ ] At least 2-3 responsive search ads per ad group
- [ ] Headlines utilize keyword themes
- [ ] Descriptions include value props and CTAs
- [ ] Display URLs are clean and relevant
- [ ] Ad extensions configured:
  - [ ] Sitelinks
  - [ ] Callouts
  - [ ] Structured snippets
  - [ ] Call extensions (if applicable)
  - [ ] Location extensions (if applicable)

## Keywords

- [ ] Brand terms in dedicated campaign
- [ ] Non-brand categorized by theme
- [ ] Initial negative keyword list applied
- [ ] No duplicate keywords across ad groups

## Tracking Verification

- [ ] Test conversion by completing a test action
- [ ] UTM parameters appended (if not using auto-tagging)
- [ ] Landing pages load correctly
- [ ] Landing page URLs match ad destinations

## Post-Launch (Week 1)

- [ ] Day 1: Check for disapproved ads, fix immediately
- [ ] Day 2-3: Review search terms report, add negatives
- [ ] Day 7: First performance review, adjust bids if needed

## Pharma/Healthcare Specific

If client is in healthcare vertical:

- [ ] Review Google's healthcare and medicines policy
- [ ] Verify certification status (if required)
- [ ] Audit ad copy for policy compliance
- [ ] Confirm landing page meets policy requirements
- [ ] Check targeting restrictions by country
